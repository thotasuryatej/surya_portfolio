# Patel's Dhaba — Restaurant Website

A small static website for Patel's Dhaba in Erragadda, Hyderabad: a welcome page with a link to the menu, and a menu
page showing the menu cards.

## Contents

| Path | What it is |
| --- | --- |
| `index.html` | Welcome page |
| `menu.html` | Menu page |
| `logo.png`, `menu1.jpg` – `menu7.jpg` | Logo and menu images |

## View it

Open `index.html` in a browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from branch).
