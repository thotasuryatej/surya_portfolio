# A Machine Learning Approach for Efficient Task Scheduling in Fog Computing

Comparing scheduling algorithms for assigning tasks to virtual machines in a fog-computing environment:
**FCFS**, **Round Robin**, **Shortest Job First** and **PBKMS**. Each is evaluated on makespan, speedup, efficiency
and task assignment.

## Contents

| Path | What it is |
| --- | --- |
| `Untitled.ipynb` | The analysis notebook |
| `unified_dataset_with_task_labels.csv` | The task dataset used in the notebook |
| `index.html`, `css/`, `js/`, `images/` | A small website presenting the results and comparison graph |

## View it

Open `index.html` in a browser, or enable GitHub Pages for this repository (Settings → Pages → Deploy from branch).
To rerun the analysis, open the notebook in Jupyter with the CSV in the same folder.
